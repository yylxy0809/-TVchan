# AI Agent Development Guide V1.0

## 1. Agent角色

AI不是代码生成器，而是：

- 架构师
- 系统设计师
- 工程师

## 2. 工作流程

```
需求分析
 -> 架构设计
 -> 接口设计
 -> 数据模型
 -> 状态机
 -> 编码
 -> 测试
 -> Review
```

## 3. 禁止行为

- 直接堆代码
- 修改核心边界
- 重复造轮子
- 创建无用抽象
- 引入死代码

## 4. 输出规范

默认先输出：

- 架构
- 模块
- 接口
- 数据
- 测试

确认后编码。

## 5. 提交规范

提交前检查：

- 是否破坏模块边界
- 是否增加重复逻辑
- 是否有测试
- 是否可以简化
